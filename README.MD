# 🌐 Site Institucional

Site institucional desenvolvido para apresentar os serviços, informações e formas de contato de uma profissional da área da saúde.

## 📋 Sobre o projeto

Este projeto foi desenvolvido como uma forma de colocar em prática conhecimentos de desenvolvimento Front-end, criando um site moderno, responsivo e com foco em uma boa experiência para o usuário.

O site apresenta informações sobre os serviços oferecidos, formas de contato e outros conteúdos relevantes para os visitantes.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## ✨ Funcionalidades

- Design responsivo para diferentes tamanhos de tela
- Menu de navegação
- Seção de apresentação
- Seção de serviços
- Formulário de contato
- Validação de formulário com JavaScript
- Seção de perguntas frequentes (FAQ)
- Depoimentos
- Botão de contato pelo WhatsApp
- Animações e efeitos visuais

## 📱 Responsividade

O site foi desenvolvido para funcionar em diferentes dispositivos, incluindo:

- 💻 Computadores
- 📱 Smartphones
- 📲 Tablets

## 🎯 Objetivo

O objetivo do projeto foi desenvolver um site institucional completo e, ao mesmo tempo, aprimorar meus conhecimentos em HTML, CSS e JavaScript por meio de um projeto prático.
